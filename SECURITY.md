# Security / Безопасность

Плагин выполняет QML/Python с правами вашего пользователя и использует локальные адаптеры оболочки. Устанавливайте только исходники, которым доверяете.

Для сообщения об уязвимости используйте вкладку Security → Report a vulnerability, если она доступна. Не публикуйте токены или приватные аудиоданные в issue; при отсутствии приватного канала начните с общего описания без секрета и эксплуатационных деталей.

В первую очередь исправляется текущая опубликованная версия. Отдельный срок поддержки старых выпусков и гарантированное время реакции не установлены.
