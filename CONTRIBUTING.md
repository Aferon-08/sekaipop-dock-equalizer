# Участие в проекте

Перед изменениями прочитайте [DEVELOPMENT.md](docs/DEVELOPMENT.md). Для ошибки достаточно issue со средой, шагами воспроизведения и коротким видео/фрагментом журнала; не прикладывайте личные аудиозаписи и токены.

Для pull request:

1. Опишите конкретную проблему и ожидаемый результат.
2. Сохраняйте интерфейсы host/адаптеров и поведение остальных модулей.
3. Прогоните проверки из DEVELOPMENT.md. При изменении JS-планировщика пересоберите WorkerScript; при изменении shader — QSB.
4. Проверьте анимацию на GPU, а не только расчёт координат: обратный проход по трубе, смену контейнера, перекрытия, pause/resume и разделение/слияние.
5. Укажите, что действительно проверено, и чего ваша проверка не покрывает.

Не включайте окружения Python, модели, записи музыки, кеши, копии настроек shell, личные пути и несвязанные изменения. Патчи предоставляются на условиях GPL-3.0 проекта.

## Публикация владельцем

Крупные обновления публикуются на GitHub после проверки. Мелкие изменения и исправления публикуются только по отдельному запросу владельца. Перед началом новой работы получите изменения из main и сохраните правки владельца.
