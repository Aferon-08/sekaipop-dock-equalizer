# Изменения

Ниже — сводка функциональных этапов, а не полный журнал коммитов. История разработки до первой публикации велась локально; она не представлена как вымышленная Git-история.

## 3.0.0-rc.1 — предварительная интеграция

- Нативные точки входа Dock.qml / Wallpaper.qml / Settings.qml; вместо установщика — стандартное подключение хостом. Требуется предложенный API оболочки, ещё не включённый upstream.
- Патч API для рассмотрения сопровождающим SekaiPOP; скрытое автоматическое исправление файлов оболочки не применяется.
- Восстановлено API временной музыкальной палитры, которое было удалено обновлением оболочки. Проверены применение и возврат исходных цветов.
- Оптимизирован многоголосный интерфейс: кеш границ финала и приостановка скрытых строк/областей.
- Включены локальные исправления 2.22.1–2.22.2, сохранность пользовательских аудиозаписей и таймингов при обновлении кода.

## 2.22.2 — локальный фикс, ещё не опубликован

- Убрано изображение обоев внутри настроек. Основная поверхность прозрачна со слабой системной тонировкой.
- Реальные окна текущего рабочего стола захватываются через ScreencopyView для преломления, без копирования самой панели. Обновление ограничено 12 Гц; закрытие освобождает источники.
- Захват работает в памяти, без сохранения и отправки изображений. В местах без окна рабочий стол виден напрямую, без искажения.

## 2.22.1 — локальный фикс, ещё не опубликован

- Снимок настоящего телефона готовится и декодируется до скрытия исходного компонента; для захвата добавлен контейнер ненулевого размера.
- Открытие: деформация снимка телефона → растекание → выдержка → прямоугольная панель. Базовый темп 1100 мс даёт примерно 3,3 с на полный переход.
- Отдельное закрытие: сжатие в маленькую каплю → короткая выдержка → быстрое расширение → плавный возврат к снимку телефона (~3 с).
- Преломление снимка обоев, выпуклая кромка, направленный блик и слабая хроматическая кайма; снимки держатся в памяти, не отправляются в сеть.
- Проверены повторные открытия и очередь закрытия/повторного открытия; старый снимок не запускает новый переход до готовности свежего.

## 2.22.0

- 55 работающих параметров вместо 20: анимации, компоновка, шрифты, прогресс, след, обои и питомец.
