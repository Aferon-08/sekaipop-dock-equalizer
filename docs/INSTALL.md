# Установка 3.0.0-rc.2

[Статус и инструкция native API](NATIVE-INTEGRATION.md).

Эта предварительная версия устанавливается как обычная папка плагина в оболочку с предложенным native API. install.py ничего не меняет. До включения API в официальную оболочку установка через каталог не может считаться готовой.

Для прежней v2.22.0 используйте документацию соответствующего тега GitHub. Обновление кода v3 не сбрасывает пользовательские записи, разметки или seed. Для удаления кода применяется штатный менеджер (для репозиториев, установленных им); данные сохраняются по выбранной пользователем политике менеджера.

Базовые зависимости прежние: Quickshell, Python 3, CAVA, setpriv/nice, PipeWire-Pulse/PulseAudio. Необязательные обработчики — setup-wordtime.py, setup-multivoice.py и setup-cuda.py; они подготавливают окружения в каталоге данных, а не интеграцию в оболочку.
