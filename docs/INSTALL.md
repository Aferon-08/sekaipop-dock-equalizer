# Установка и обслуживание

[← README](../README.md)

## Поддерживаемая среда

Это дополнение к установленному SekaiPOP, а не установщик рабочего окружения. Оно проверено на Arch/CachyOS, Hyprland 0.57, Quickshell 0.3.2, Qt 6.12 и SekaiPOP 1.0.0 на commit `69e1df0f282ca9a5193c1a628b346e5df01c7d93`. Это проверенная конфигурация, а не обещание совместимости с любой сборкой с тем же номером версии.

Нужны:

| Для чего | Зависимости |
|---|---|
| Док и обои | Рабочий SekaiPOP с API плагинов 1, Quickshell, Qt Quick с аппаратными шейдерами, Python 3. |
| Звуковая визуализация | `cava`, `setpriv` и `nice` (util-linux/coreutils), PipeWire-Pulse или PulseAudio. |
| Получение проекта | Git либо архив релиза. |
| Запись Spotify | `pactl`, `parec` из утилит PulseAudio, работающая совместимость PipeWire-Pulse. |
| Локальные тайминги/голоса | `uv`, Git, FFmpeg/ffprobe, интернет на подготовку окружений и моделей, достаточно дискового пространства. |
| NVIDIA-анализ | Поддерживаемый драйвер NVIDIA, `nvidia-smi`, отдельное CUDA-окружение; CPU-окружение сохраняется как запасной вариант. |

Для Arch-подобной системы, где SekaiPOP уже работает, дополнительные пакеты можно установить так:

```sh
sudo pacman -S --needed git python cava util-linux coreutils libpulse ffmpeg uv
```

Не заменяйте работающий звуковой сервер только ради плагина. На других дистрибутивах имена пакетов отличаются.

## Новая установка

```sh
git clone https://github.com/Aferon-08/sekaipop-dock-equalizer.git
cd sekaipop-dock-equalizer
python3 install.py
```

Либо скачайте ZIP из [Releases](https://github.com/Aferon-08/sekaipop-dock-equalizer/releases), распакуйте и выполните `python3 install.py` в папке с этим файлом. `sudo` для установки самого плагина не нужен.

Установщик:

1. Проверяет структуру дока и обоев до записи изменений.
2. Сохраняет текущие `Dock.qml`, `WallpaperLayer.qml`, `EditChrome.qml` и предыдущую папку плагина.
3. Останавливает оболочку, копирует плагин и добавляет пять обратимых подключений.
4. Сбрасывает записи, разметки, отметки прослушивания и временное аудио; создаёт новый installation seed.
5. Запускает оболочку; при ошибке внутри процедуры восстанавливает сохранённые файлы.

Резервные копии находятся в `$XDG_STATE_HOME/sekaipop/dock-equalizer-backups/` (обычно `~/.local/state/sekaipop/dock-equalizer-backups/`). Модели и Python-окружения при переустановке не удаляются. Пользовательские настройки сохраняются.

Полную переустановку выполняйте после завершения записи/анализа. Для обычного обновления используйте следующий раздел.

## Обновление и восстановление без потери данных

```sh
cd sekaipop-dock-equalizer
git pull --ff-only
python3 install.py --repair
```

Используйте ту же команду после обновления SekaiPOP, если оболочка заменила файлы с адаптерами. Режим сохраняет разметки, записи, настройки и installation seed. При обнаруженном активном задании сервисом установщик откажется от перезапуска: дождитесь его завершения или отмените анализ в интерфейсе.

Номер версии оболочки сам по себе недостаточен: установщик проверяет конкретные участки QML. Сообщение «структура изменилась» означает, что нужен обновлённый адаптер; не обходите проверку ручной вставкой блоков.

Для другой папки оболочки:

```sh
python3 install.py --shell-dir /путь/к/sekaipop --repair
```

Поддерживаются `XDG_CONFIG_HOME`, `XDG_STATE_HOME`, `XDG_DATA_HOME` и `SEKAIPOP_PLUGINS_DIR`. Стандартный путь плагина — `~/.config/sekaipop/plugins/dock-equalizer/`. `--no-restart` предназначен для уже остановленной оболочки; установку в работающую оболочку он не разрешает.

## Необязательные обработчики лирики

Базовый док, штатная лирика, обои и импорт JSON работают без них. Запускайте команды из папки проекта либо установленного плагина:

```sh
# Основное окружение, закреплённый extractor и Whisper base.
python3 setup-wordtime.py

# Необязательные модели выделения/сопоставления голосов.
python3 setup-multivoice.py

# Необязательное отдельное NVIDIA CUDA-окружение.
python3 setup-cuda.py
```

Подготовка доступна также из окна таймингов в доке. Используются изолированные окружения в каталоге данных; системный Python не изменяется. Потребуется несколько гигабайт, особенно для PyTorch/CUDA. Модели не входят в архив репозитория.

После подготовки выберите устройство анализа и количество CPU-потоков в настройках плагина. NVIDIA определяется через `nvidia-smi`, устройство закрепляется по UUID; CUDA не должна случайно выбирать встроенную Intel-графику. Отрисовка QML — отдельный процесс оболочки и отдельная настройка PRIME. Установщик не меняет драйверы, Hyprland или способ запуска оболочки.

## Проверка

```sh
qs -c sekaipop ipc call plugins list
qs -c sekaipop ipc call dockequalizer status
qs -c sekaipop ipc call proceduralwallpaper-eDP-1 status
```

Замените `eDP-1` именем монитора из `hyprctl monitors`. Статус `desktop off` у Dock Equalizer означает выключенную отдельную карточку виджета и **не означает**, что интеграция дока/обоев отключена.

## Удаление

Из сохранённой копии проекта, не из удаляемой установленной папки:

```sh
python3 install.py --uninstall
```

Команда снимает подключения, удаляет установленную папку плагина и перезапускает оболочку. Сохранённые данные/модели и настройки автоматически не очищаются. При необходимости удалить их можно отдельно после резервного копирования:

- `~/.local/share/sekaipop/dock-equalizer/` — записи, модели и разметки;
- `~/.local/state/sekaipop/plugins/dock-equalizer.json` — настройки;
- `~/.local/state/sekaipop/dock-equalizer-backups/` — резервные копии.

Учитывайте свои XDG-пути. Не удаляйте весь каталог `sekaipop`: он содержит данные других плагинов.
