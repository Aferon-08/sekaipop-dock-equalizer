# 3.0.0-rc.1: штатные поверхности, предложение API

Это предварительная версия. **На официальном SekaiPOP commit 036afe4 необходимых точек расширения ещё нет.** Плагин не объявляется готовым для Reviewed list до принятия соответствующего API сопровождающим SekaiPOP.

## Что изменилось

Плагин больше не патчит файлы оболочки, не запускает install.py при загрузке и не сбрасывает записи при обновлении. Используются три входных компонента: Dock.qml, Wallpaper.qml и Settings.qml. Их создаёт оболочка и передаёт `host` с темой, геометрией и состоянием. install.py оставлен только как сообщение о новом способе установки; он ничего не изменяет.

В `plugin.json` объявлены `extensions: ["dock", "wallpaper", "settings"]`. Возможности определяются по `host.capabilities`, а не только номеру `VERSION=1.0.0`: номер версии у разных обновлений SekaiPOP одинаковый. При отсутствии API плагин уведомляет о несовместимости, вместо скрытого запуска установщика.

## Патч для автора оболочки

[`integration/sekaipop-native-extensions.patch`](../integration/sekaipop-native-extensions.patch) подготовлен относительно официального commit **036afe49b6ee40bf18c01efdb585f000422c7c21**. Он не привязан к id данного плагина. Патч добавляет:

- Декларацию и валидацию surfaces в манифесте.
- Хосты дока, обоев и пользовательской страницы настроек.
- Реестр настроенных прямоугольников виджетов в оболочке.
- Явный набор capabilities; управление жизненным циклом поверхностей при загрузке/удалении.
- API временной музыкальной палитры с восстановлением исходной палитры и истечением аренды.

В исходном checkout SekaiPOP для рассмотрения:

```sh
git switch --detach 036afe49b6ee40bf18c01efdb585f000422c7c21
git apply --check /path/to/sekaipop-native-extensions.patch
git apply /path/to/sekaipop-native-extensions.patch
```

Это изменение **самой оболочки**, которое должен рассмотреть её автор. Плагин не выполняет эти команды. Нельзя гарантировать сохранение локального патча после обновления на непатченную официальную оболочку. Надёжное решение — принятие API upstream, а не автоисправление файлов сторонним плагином.

На машине владельца API применён и проверен; исходные файлы оболочки и прежний плагин сохранены в `~/.local/state/sekaipop/dock-equalizer-backups/native-api-*`.

## Проверить предварительную версию

Нужен SekaiPOP с этим API. Распакуйте архив предварительного релиза в каталог `~/.config/sekaipop/plugins/dock-equalizer/` (заменяя только файлы кода), затем перезапустите оболочку. Сохранённые настройки, записи и разметки находятся вне каталога кода и сохраняются.

После принятия API и выпуска плагина в основной ветке штатный менеджер сможет клонировать/подключать этот же формат одной кнопкой без специальных шагов. Устанавливать нынешнюю ветку main через менеджер ради теста v3 пока не следует: main содержит стабильную v2 с прежними адаптерами.

```sh
qs -c sekaipop ipc call dockequalizer status
```

`nativeIntegration: true` подтверждает обнаружение возможностей хоста. Проверьте также статусы `docklyrics-<monitor>` и `proceduralwallpaper-<monitor>`: обнаружение одного манифеста не доказывает успешную отрисовку.

## Каталог

После рассмотрения API и проверки установки понадобится отдельная заявка в SekaiPOP: запись в `plugins.json` и синхронное изменение раздела Plugins README оболочки. До назначения версии, включающей API, нельзя честно указать минимальную совместимость просто как `1.0.0`. Заявка/PR от имени владельца автоматически не отправлялись.

## Производительность

Конец каждой партии теперь вычисляется по сохранённым границам таймлайна, вместо повторного разбора всей песни на каждом кадре. Скрытые голосовые области и одиночная лирика под многоголосным видом не держат активные строки. Результаты финалов сохранены; это оптимизация отображения, не новая модель распознавания певцов.

На частной копии лирики указанного владельцем трека: медиана отдельной сцены ~35 → ~17 мс; в оболочке на двух мониторах после прогрева — ~14 мс, p95 ~27 мс. Эти числа описывают конкретный прогон, не обещают одинаковой частоты кадров на любом GPU и не включают тяжёлый анализ аудио. Текст/записи песни в репозиторий не включены.
