# Диагностика и ограничения

[← README](../README.md)

## Всё пропало после обновления SekaiPOP

Обновление могло заменить три файла с локальными подключениями. Из копии проекта:

```sh
python3 install.py --repair
```

Если адаптер отказался из-за структуры QML, сохраните сообщение и версию/commit оболочки для issue. Не запускайте обычную переустановку ради ремонта, если хотите сохранить записи и тайминги.

## Плагин указан как desktop off

Это статус отдельного виджета рабочего стола. Док и обои подключены независимо. Проверяйте параметры `enabled`, `proceduralWallpaper` и фактические IPC-статусы.

## Капсулы не появились

Проверьте воспроизведение в MPRIS-плеере, доступность CAVA, вывод звука и свободное место по краям дока. При длине менее 64 px капсула скрывается. Блокировка, Game Mode и скрытый док тоже ограничивают работу.

```sh
qs -c sekaipop ipc call dockequalizer status
qs -c sekaipop log -t 100
```

`running: false` при паузе — ожидаемое отключение аудиопотока. Если браузер не публикует MPRIS/длительность/позицию, плагин не может гарантировать полноценное управление. Для YouTube предусмотрено уточнение длительности, но оно также зависит от доступности источника.

## Нет лирики или несколько голосов распознаны неправильно

Проверьте совпадение версии записи и текста. Данные источника могут не содержать подпевки. Импортируйте более точный JSON или выберите правильный аудиофайл и запросите повторный анализ. Хор/двойная запись одного певца не всегда означают отдельных персонажей.

## Долгий анализ

Стадия голосов может выполнять несколько моделей, поэтому процент прогресса не является линейным таймером. Выберите разумное число CPU-потоков и подготовьте CUDA-окружение при наличии NVIDIA. Уменьшение нагрузки на интерфейс не ускоряет модель на CPU автоматически. Для диагностики:

```sh
qs -c sekaipop ipc call docklyrics-eDP-1 wordtimeStatus
```

Смените имя монитора на своё. Не отменяйте и не перезапускайте задание только потому, что процент некоторое время стоит на месте; сначала посмотрите этап и загрузку CPU/GPU.

## Дёргаются обои или не работает стекло

Нужен аппаратный Qt Quick renderer. Программный renderer/llvmpipe не является целевой конфигурацией. Проверьте драйверы и способ запуска самой оболочки. При PRIME желательно понимать, какая GPU рисует весь процесс: плагин не переносит отдельные QML-объекты на другую GPU. Переменные для CUDA-анализа этого не меняют.

Для снижения нагрузки отключите движение фигур, затем питомца. Высокий DPI, несколько мониторов, стеклянные слои и большая площадь текстур повышают стоимость кадра. Редкие задержки на всех конфигурациях не считаются полностью устранёнными только на основании короткой локальной проверки.

## Что приложить к bug report

Версию плагина и commit SekaiPOP, версию Quickshell/Qt/Hyprland, GPU и renderer, масштаб и число мониторов, шаги воспроизведения и относящийся к сбою фрагмент журнала. Для анимации полезно короткое видео. Не прикладывайте записи музыки, токены и весь домашний каталог.
