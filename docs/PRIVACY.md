# Данные и сеть

[← README](../README.md)

## Что остаётся локально

Стандартная папка: `$XDG_DATA_HOME/sekaipop/dock-equalizer/`, обычно `~/.local/share/sekaipop/dock-equalizer/`.

| Каталог/файл | Назначение |
|---|---|
| `recordings/` | Полные записи выходного потока Spotify для повторного расчёта. |
| `recording-seen/` | Локальные отметки записи/прослушивания. |
| `wordtimes/` | Проверенные тайминги и результаты анализа партий. |
| `audio-tmp/` | Временное аудио обработки. |
| `runtime/`, `runtime-cuda/`, `multivoice-runtime/` | Изолированные Python-окружения. |
| `models/`, закреплённые исходники extractor/UNMIXX | Загруженные модели и вспомогательный код. |
| `wallpaper-install-id` | Идентификатор для генерации новых обоев при переустановке. |

Настройки: `$XDG_STATE_HOME/sekaipop/plugins/dock-equalizer.json`. Геометрия виджетов передаётся между компонентами в памяти; модуль не делает снимки личного рабочего стола для построения обоев.

## Аудио

CAVA получает монитор системного выхода, пока нужен музыкальный визуализатор. Это общий выход, а не только выбранная песня. Запись для анализа Spotify — отдельная функция: выбирается поток самого Spotify, микрофон не используется.

**Запись Spotify включена по умолчанию** и не требует нажатия генерации. Выключается в настройках плагина. Она нужна для полного аудио той же версии песни; сырая запись занимает приблизительно 10 МБ/мин. Тяжёлый анализ начинается только после ручного запроса и наличия необходимых данных. Первая установка и полная переустановка очищают записи и разметки; обновление через `--repair` сохраняет их.

Плагин не загружает записи Spotify в облачный сервис распознавания и не публикует их в GitHub. Диагностика и скриншоты, которыми вы делитесь в issues, могут содержать названия прослушиваемых треков и локальные пути: просмотрите их перед отправкой.

## Когда используется сеть

- Штатный LyricsService SekaiPOP получает лирику по метаданным трека.
- Подготовка обработчиков загружает исходники, Python-зависимости и модели с upstream-сервисов.
- Запрошенная обработка YouTube может получать метаданные и аудио соответствующего URL через yt-dlp. Доступность зависит от источника.
- Git/GitHub используются при установке и обновлении.

В репозитории нет личных песен, пользовательских кешей, подготовленных окружений, токенов или записей рабочего стола. Отключение сетевых источников может ограничить поиск лирики, но локальная процедурная сцена не требует сети.

## Стеклянная панель настроек

Пока панель открыта, видимые окна текущего монитора предоставляют изображение через ScreencopyView для локального преломления. Частота ограничена 12 Гц. После закрытия источники освобождаются. Это может включать содержимое приложений за панелью; по умолчанию оно не сохраняется на диск и не отправляется в сеть. В пустых участках рабочий стол виден напрямую. Явная диагностическая команда snapshot сохраняет изображение только по запросу пользователя.

В музыкальном доке тот же способ применяется только к окнам, пересекающим область дока, с частотой до 8 Гц. При исчезновении музыкального стеклянного корпуса захват прекращается. Содержимое остаётся в памяти и не передаётся в сеть; пустой рабочий стол просвечивает без преломления.
